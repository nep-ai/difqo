# Security policy

Difqo is in pre-MVP development. Supported versions will be listed here when software releases begin.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/nep-ai/difqo/security/advisories/new) for suspected vulnerabilities in Difqo. Include the affected URL or revision, the potential impact, and enough detail for maintainers to reproduce the issue. Use redacted examples and remove secrets and personal data. Keep vulnerability details out of public issues, pull requests, and chats while maintainers investigate.

If you cannot use GitHub’s form, email the [Nep AI team](mailto:info@nepai.com.np) with “Difqo security” in the subject to arrange a private handoff. Maintainers will use the private report to coordinate remediation and any public advisory.
