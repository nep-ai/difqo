# Difqo

Open source Agent Factory for Solo Builders and Small Teams

Difqo is in development. We’re building a way for coding agents to carry project decisions from one task to the next and bring the work back to you for review.

[Join the early-access waitlist](https://difqo.com/#waitlist) to hear when access opens. You can also tell us which task you want Difqo to take off your plate.

## A task with project memory

Imagine asking for a CSV export on a reports page. An earlier decision says that each workspace can only read its own rows. In the planned workflow, the team retrieves that rule, uses it to scope the export query, and shows you a check using records from two workspaces before you accept the change.

[Read the illustrated workflow on difqo.com](https://difqo.com/examples/project-memory).
